# Text experiment: can the cloud read a private name? (D-177)

Generated by `benchmark/bench/score-textexp.mjs` (2026-11-26). Counts only; the names themselves are not in this file.

**Why.** The vault exists to catch private words in a photo: a child's name on a bag, an employer on a badge. The geolocation test above can't show whether hiding them works, because the attacker prompt is told not to repeat names. So this test asks the cloud directly to transcribe all visible text.

**Method (pre-registered).** 24 benchmark photos, each with one drawn card carrying a made-up first name in capitals (8 small, 8 medium, 8 large: text 1.5%, 2.5% and 4% of the image height). The device first ran the app's own OCR and vault match on the unmasked photo. Then `gemini-3.5-flash-lite` was asked once per version to "transcribe every piece of readable text" (prompt `textProbe.dev1`, no tools; run under the name textProbe.v1 with the same text) on the same ≤ 1536 px copy the app would send, with the card: unmasked, under a light blur (sigma 4% of the card's shorter side), under a strong blur (15%, unreadable to a person), or solid-filled as the app does. Faces are solid in every version. "Read" means the app's own fuzzy matcher finds the name in the answer.

## Results

| | Photos | Share | 95% interval |
|---|---|---|---|
| **The device's OCR caught the name before anything was sent** | **22 / 23** | 96% | 79–99% |
| The cloud read the name: No mask | 23 / 23 | 100% | 86–100% |
| The cloud read the name: Light blur | 23 / 23 | 100% | 86–100% |
| The cloud read the name: Strong blur | 0 / 23 | 0% | 0–14% |
| The cloud read the name: Solid fill (the app) | 0 / 23 | 0% | 0–14% |

| Text size | Photos | Device caught | Cloud read: none / light blur / strong blur / solid |
|---|---|---|---|
| small | 8 | 7 | 8 / 8 / 0 / 0 |
| medium | 7 | 7 | 7 / 7 / 0 / 0 |
| large | 8 | 8 | 8 / 8 / 0 / 0 |

1 photo(s) not scored (a refusal, an error, or a face the gate would block).

**Limits.** Drawn cards in clean capitals are easier to read than real handwriting or a name at an angle; one model, one call per version. A blur's strength decides what survives it; this tests two strengths. The device-side catch uses the same OCR and matcher the app runs before the consent screen.
